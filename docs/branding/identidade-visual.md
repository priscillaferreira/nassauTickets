# Identidade Visual — nassauTickets

## Logotipo
![Logo nassauTickets](logo.svg)

Um **ticket** (bilhete) azul com uma **cruz verde-água** (saúde/laboratório) e o picote tracejado,
remetendo à senha impressa pelo totem. Arquivo vetorial: [`logo.svg`](logo.svg).

Nome: **nassau**Tickets — "nassau" em peso normal e "Tickets" em negrito.

## Paleta de cores
| Uso | Cor | Hex |
|-----|-----|-----|
| Primária (marca, senha SG) | Azul Nassau | `#0057A8` |
| Secundária (detalhes decorativos, nunca atrás de texto) | Verde-água saúde | `#00A19A` |
| Senha **SP** – Prioritária | Vermelho | `#C62828` |
| Senha **SE** – Retirada de Exames | Roxo | `#6A1B9A` |
| Senha **SG** – Geral | Azul | `#0057A8` |
| Sucesso | Verde | `#2E7D32` |
| Aviso / "Última chamada" | Âmbar | `#9A5B00` (botões) / `#FFB300` (selo, com texto escuro) |
| Fundo | Cinza-azulado claro | `#F4F7FB` |
| Texto | Grafite | `#1A2433` |

Todas as cores usadas com texto branco (senhas e botões) têm contraste **≥ 4,5:1** (WCAG AA).
A informação **nunca depende só da cor**: o tipo da senha também é escrito por extenso.

## Tipografia
- **Segoe UI / Roboto / Arial** (fontes do sistema, sem download).
- Painel: números de senha grandes (até 4,5 rem) para leitura à distância.

## Tom de voz
Frases curtas, educadas e diretas: "Aguarde ser chamado no painel", "Dirija-se ao guichê 2".
